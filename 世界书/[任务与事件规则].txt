# 委托任务
- 仅在委托明确成立，且有具体目标、交付对象与酬劳时建立历练；闲谈、传闻、口头提及和一轮即结的小互动不建卡。
- 同一委托只保留一个名称，推进时更新原条目，不重复建卡；名称不得含 / 或 ~。
- 接取、目标实质变化或达到交付条件时输出以下面板；普通交涉不重复输出。
<task_info>
{任务名称}
| 状态: [进行中|待结算] | 难度: [境界] |
| 委托方: [人物或组织] | 截止时间: [YYYY年M月D日时辰|无] |
| 目标: [一句话达成条件] |
| 进展: [当前最新进展] |
| 奖励: [具体奖励] |
| 交付: [对象、地点与交付条件] |
</task_info>
- 接取后写入 stat_data.历练；目标达成记为“待结算”。实际交付后发放一次奖励并移除条目；失败或放弃同样移除。
</rule>
