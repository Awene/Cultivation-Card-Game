# 冥界设计 · 进度与待办清单

> 记录「世界层级新增冥界」的已定设计决策与全部待设计内容。
> 创建：2026-08-09。随讨论持续更新。

## 一、已定设计（共识）

### 定位

- 冥界 = **新生线** + **独立可停留地图**：玩家死后进入冥界，可选择开启幽冥生涯。
- 世界体系：`凡界 → 灵界 → 仙界` 为阳世飞升主线；**冥界为诸界之影、众生死亡之所归，与凡界阴阳平行**（不在飞升主线上）。

### 死亡与转生机制

- **触发分层**：
  - 练气/筑基（无元神）：肉身死亡 → 魂魄入冥
  - 金丹/元婴（有元婴/元神）：肉身死但元神可遁逃 → 夺舍/重修/被宗门捞回，未必入冥
  - 化神以上：元神遨游，几乎不死
  - **魂飞魄散：不入冥（真死）**——需界定「灭神」级手段
- **流程**：接引 → 判官审功过 → **孟婆汤抉择（核心分叉）**

| 抉择 | 后果 | 路线 |
| --- | --- | --- |
| 喝汤（转世投胎） | 前尘尽忘、**修为清零**、关系清零 | 彻底新生 |
| 拒喝（保留执念） | 保留记忆与修为，转生**冥族/鬼修**（死法决定形态） | 幽冥生涯（B 线主场） |

- **冥族形态由死法决定**：寻常战死/坐化→幽魂；含怨→怨煞；被炼尸/剥皮/虐杀→行尸/白骨；阴德深厚/有冥缘→起点优待。

### 幽冥生涯（B 线）

- 冥界为主场：冥修境界、幽冥势力、鬼道技艺、阴煞/香火/阴德资源。
- **借尸还魂**（冥族天赋）可回凡界以新身份行动，前世人情不断。
- 势力三角：**凡界幽冥府 ↔ 灵界黄泉大陆 ↔ 冥界幽冥司**。
