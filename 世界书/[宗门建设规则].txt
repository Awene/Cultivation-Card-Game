<rule name="宗门建设规则">
# 参数声明:
  L=设施境界系数 Q=品质系数，沿用核心系数总表；负责人、素材分别取自身L/Q
  U=领取时所属资产的名气
  Z(a)=L×(1+Q)×a                  # 百分数值，效果写作Z(a)%
  N=floor((L+1)×(1+Q))            # 月度名气增减量；活动增减量=3N
  商业月净收益=floor(U×10^L×(1+Q)/100)

# 核心触发条件:
  <user>是资产拥有者（宗主、店主、府主等），且实际实施其设施的新建、升级或修复。

# 第一阶段: 建设检查
  逻辑与规则:
    1. 确定用途、规模、目标境界、负责人、建材
    2. 主材取核心建材中L最高者，同L取Q最高者；未指定时，目标境界=主材境界；负责人L须≥目标L
    3. 建设费C=ceil(10^目标L×K)灵石；新建K=10，升级K=5，修复K=2
    4. 检查未通过→失败，不扣费扣料；通过→扣除C与本次用料，再判定

  面板模板:
  <action_info>
    {建设检查}
    | 资产: [名称] | 设施: [名称] | 建设目标:[境界] | 操作: [新建/升级/修复] |
    | 负责人: [姓名] | [技艺]=[技艺值] |
    | 境界检查: 负责人L[值]≥目标L[值] -> [通过/失败] |
    | 建设费C: ceil(10^[目标L]×[K])=[费用] | 当前灵石[值]≥C[值] -> [通过/失败] |
    | 建材: [主材][辅材1][辅材2]... | 用量检查: [齐备/不足] -> [通过/失败] |
  </action_info>

# 第二阶段: 素材与建造判定
  逻辑与规则:
    1. 基准: Vt=10^目标L，Vu=10^负责人L
    2. 素材能效与品质区间:
      - 本次投入的核心建材按种类计算；下限Min_Q=最低品质，上限Max_Q=最高品质
      - 主材能效=10^主材L×(1+主材Q)
      - 辅材能效=10^辅材L×(1+辅材Q)×E；辅生主E=1.5，主生辅1.2，无生克1，相克0.5
      - 有效能效P_mat=主材能效+最高的前三种辅材能效
      - 杂质难度D_mat=Σ(10^素材L×0.5)，计入全部核心主辅材
    3. 正面影响(P):
      公式: P=Vu+相关技艺+工具加值+阵法加成+功法加成+P_mat；同类加成取最高一项
    4. 反面影响(D):
      公式: D=Vt×2+D_mat+无图纸惩罚
      有图纸时惩罚=0，否则为Vt×0.5；重复建设/修复视为有图纸
    5. 差值结算与品质推演:
      - Δ=P−D；Δ<0失败，0≤Δ<0.5Vt成功，0.5Vt≤Δ<Vt优秀，Δ≥Vt极品
      - 成功/优秀/极品: Min_Q提升0/1/2阶，按凡→黄→玄→地→天排列，以Max_Q封顶，再查Q系数
    6. 建设结果:
      - 新建采用目标境界与候选品质；升级须达到声明目标且境界、品质不低于原设施；修复须候选品质≥原品质，恢复原状
      - 达标即建成；Δ<0或未达标则失败，消耗已投入费用和材料，原设施及受损状态保留

  面板模板:
  <action_info>
    {素材分析}
    | 基准: Vt=10^[目标L]=[值]；Vu=10^[负责人L]=[值] | 品质区间: [Min_Q]～[Max_Q] |
    | 主材: [名称、数量、L/Q、五行] | 能效: 10^[L]×(1+[Q])=[值] |
    | 辅材: [名称、数量、L/Q、五行] | E=[生克系数] | 能效: 10^[L]×(1+[Q])×[E]=[值] | (每种一行)
    | 有效能效(P_mat): [主材值]+[前三辅材逐项值]=[合计] |
    | 杂质难度(D_mat): Σ(10^[各核心素材L]×0.5)=[合计] |
    {数值对抗}
    | 正面影响(P): Vu[值]+技艺[值]+工具[值]+阵法[值]+功法[值]+P_mat[值]=[总值] |
    | 图纸: [有/无/重复建设或修复] | 惩罚: [0或Vt×0.5，代入结果] |
    | 反面影响(D): Vt[值]×2+D_mat[值]+惩罚[值]=[总值] |
    | 差值结算: P[值]−D[值]=Δ[值] |
    {建设结算}
    | 判定门槛: 0；0.5×Vt=[值]；Vt=[值] | Δ=[值] -> [失败/成功/优秀/极品] |
    | 品质推演: [Min_Q]+[升阶数]阶，以[Max_Q]封顶 -> [候选品质、Q] | 目标核对: [达标/未达标] | (Δ≥0时)
    | 结果: [建成/失败] | 设施: [境界、品质或未建成] |
  </action_info>

# 第三阶段: 设施生成
  逻辑与规则:
    1. 建成后按最终L/Q生成效果；条数: 凡/黄/玄=1, 地/天=2。升级只改涉及的能力，其他词条和生产安排沿用。
    2. 效果写作“条件+对象+具体作用”，正常运转且实际使用时生效；物资、灵石、名气收支写入每月产出。
    3. 百分比加成用Z(a)%：普通加成a=1～2，修行速度a=0.5～1。技艺、工具、火焰按原值折算临时加值；能效、修行速度计入对应规则的Z%，叠加沿用对应规则。
    4. 阵法基础数值记入效果的“概况”：灵气容量=floor(10^L×(2～6)×(1+Q))，攻击力=floor(10^L×(0～0.3)×(1+Q))，非攻击阵法攻击力=0；消耗为无，结阵注入灵气，注满后运转。具体阵法效果按上述条数生成。

  效果示例: (优先使用示例中存在的效果)
    生产:
      - 在${生产活动}时，${技艺}临时增加${Z(1~2)}%
      - 将${设施境界}及以下的${数量}份${矿物/药材}提纯为1份同境界、品质高一阶的材料，成品品质≤设施品质
      - 此设施内生产时，已有${火焰/工具}的加值增加${Z(1~2)}%
    交易:
      - 在${地域}购买${境界}及以下的${品类}时，价格降低${Z(1~2)}%
      - 本设施内交涉时，相关技艺临时增加${Z(1~2)}%
    研习:
      - 公开${玩家持有的功法名称，可枚举多个}供本门弟子研习
      - 在阁内研读时，领悟能效增加${Z(1~2)}%
      - 此设施内打坐时，修行速度增加${Z(0.5~1)}%
    情报与接引:
      - 可搜集${境界}及以下秘境或人物线索
      - 面向${地域}招收${条件}的弟子
    阵法:
      概况写法: ${阵法名}；灵气容量:${数值}；攻击力:${数值}；消耗:无
      - ${阵法名}运转时，${作用范围}内${具体效果}

  每月产出:
    1. 物资: 按设施用途确定产物及计量单位；产物L≤设施L且产物Q≤设施Q，否则生产失败。
      月产量=floor(10^设施L×(1+设施Q)/(10^产物L×(1+产物Q)))；同境界、同品质为1份/月，产出全额归玩家。
      写法: “${产物名、境界、品质}×${数量}${单位}/月”。
    2. 商业: floor(U×10^L×(1+Q)/100)，含日常进货与经营开销；先将10^L×(1+Q)/100算成数字，保留“数字×名气”公式。
      写法: “${系数}×名气灵石/月（净收益）；主营${品类}”。
    3. 名气: 按设施用途选择月度或活动收支，名气最低为0。
      写法: “名气${+N或−N}/月”或“每完成一次${指定活动}，名气${+3N或−3N}”，增减量写成算出的整数。
    4. 无产出写“无”；产出不占效果条数。

  面板模板: (建成时，按所选效果列对应算式)
  <action_info>
    {设施建成}
    | 设施: [名称] | 境界: [境界、L] | 品质: [品阶、Q] | 效果条数: [1/2] |
    | 百分比效果: [效果名] | Z(a)%=[L]×(1+[Q])×[a]%=[结果]% | 最终描述: [条件、对象、作用] |
    | 非数值效果: [效果名、条件、范围与作用] |
    {阵法数值} (阵法设施)
    | 灵气容量: floor(10^[L]×[2～6中所选系数]×(1+[Q]))=[值] |
    | 攻击力: floor(10^[L]×[0～0.3中所选系数]×(1+[Q]))=[值] | 消耗: 无 |
    {产出核算} (按产出类型列算)
    | 产物: [名称、境界、品质、单位] | 检查: 产物L[值]≤设施L[值]且产物Q[值]≤设施Q[值] -> [通过/生产失败] |
    | 月产量: floor(10^[设施L]×(1+[设施Q])/(10^[产物L]×(1+[产物Q])))=[数量] | (检查通过时)
    | 商业系数: 10^[L]×(1+[Q])/100=[值] | 月净收益: floor([系数]×U[值])=[灵石] |
    | 名气: N=floor(([L]+1)×(1+[Q]))=[值] | 收支: [每月±N/每次指定活动±3N，代入结果] |
    {设施记录}
    | 每月产出: [最终写入内容] | 概况: [规模、投产时间；阵法另记灵气容量、攻击力] |
  </action_info>

# 变量更新要求:
  1. 按建设判定扣费扣料，建成时写入固定资产.${资产名}.设施.${设施名}的境界、品质、效果与每月产出。效果为字符串字典，“概况”记规模、投产时间及阵法基础数值，不占效果条数；门规写入资产现状。
  2. 建成时上次收取日期设为当前时间。
  3. 领取时，以当前时间与上次收取日期之差计算完整月数；每月产出×月数分别加入玩家物品、灵石及宗门名气，商业先按领取前名气计算；收取后日期更新为当前时间。活动名气在活动完成时增减。
</rule>
