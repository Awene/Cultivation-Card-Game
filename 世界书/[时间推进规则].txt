触发机制: 仅当明确要求以[时间推进规则]进行世界演进时触发
推演区间: 从变量「传闻.上次世界推进时间点」至本轮请求记录的「时间」；只补算这段已流逝的时间，不额外推进玩家时间。

# &RULE_世界变迁参考表:
  | 时间跨度 | 典型表现 |
  | --- | --- |
  | 1~5年 | 势力消长、人事更迭、局部战乱平息或爆发 |
  | 5~30年 | 王朝或宗门兴衰、灵脉枯竭或新生、秘境开闭 |
  | 30~100年 | 小型王朝或宗门陨落覆灭或崛起、势力版图重划、城市荒废或新建 |
  | 100~500年 | 大型王朝或宗门陨落覆灭或崛起、山河改道、上古遗迹重现 |
  | 500~3000年 | 大陆格局重塑、种族兴衰、旧势力彻底湮没 |
  | 3000年以上 | 世界沧海桑田、旧时代彻底成为神话 |

  | 变化类型 | 叙事说明 |
  | --- | --- |
  | 日常 | 闲谈/恋爱/娱乐/历练/经营等,内容丰富多样 |
  | 突破 | 修炼与境界提升 |
  | 技艺 | 研习、实践提升技艺 |
  | 机缘 | 获得装备/物品，注明所得 |
  | 探秘 | 探索经历简述，注明成败与得失 |
  | 制造 | 炼丹/炼器/制符/制傀等，注明成败与产物 |
  | 领悟 | 领悟功法，注明成败 |
  | 战斗 | 战胜/受伤/陨落，注明成败与得失 |
  | 身份 | 身份发生变化，如：叛出宗门、晋升长老 |
  | 陨落 | 人物死亡，从关系列表中移除 |

# &RULE_NPC寿命结算:
  突破增寿 = 100 × max(0, 2^floor(新L) − 2^floor(旧L))
  新寿命 = 旧寿命 + 突破增寿 + 本段延寿 − 本段折寿
  年龄取变量中的终点值；冥族年龄不增长。

# &RULE_NPC技艺增长:
  每项增量 = floor(10^L × T × k)，新值 = 旧值 + 增量
  L=研习时境界系数；T=该项研习天数/365；k∈[0.05,0.2]，由资质、指导与实践条件决定。
  各项T之和≤推演年数；跨境界分段计算，增量相加。
  技艺名沿用变量中生产类、战斗类字段。

# 时间推进面板
  约束:
    - (可选)用{世界变迁}记录一处势力/地域/<user>名下资产的变化，并接对应叙事；短期没有变化可省略
    - 用{人物推演}推演关系列表中的全部NPC(傀儡、灵兽除外)。每人一个完整<time_info>面板，紧接该人物经历的正文段落。禁止把全员塞进一个大面板
    - 正文开头的<tp>沿用原要求。世界推进过程中的NPC镜头、世界变迁及其时间地点切换无需输出<tp>面板
    - 按资质、修炼环境、时间与机缘推演境界变化；突破须发生在当时寿命耗尽前。
    - 非冥族终点年龄>新寿命则陨落。
    - 依照<rule ref="物品功法生成规则"/>注明NPC所得
    - 技艺增加每项一行；技艺增加、物品变动无变化时省略。
