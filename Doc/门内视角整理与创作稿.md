整理日期：2026-09-14。状态：现状已归档，待用户指导创作，尚未定稿、尚未回填。

本文以当前世界书总览中的实际 `sectsData` 为准，集中整理凡界与灵界的门内视角。下方“现有四档原文”照录当前内容，包含目前已有的重复说明；不代表本轮认可或新增这些写法。“创作稿”用于后续修改，确认后再回填。

## 使用方式

1. 用编号或“地域＋宗门名”指定本轮创作对象，在对应“用户指导”中记录要求。
2. 保留现有原文供对照，在“创作稿”中编写外门、内门、管事、长老四档；需要变更分档或身份关键词时一并记录。
3. 每个宗门确认后将状态改为“已定稿，待回填”。本文件中的编辑不会自动影响酒馆提示词。
4. 待创作完成并确认回填后，再修改总览中的对应 `门内kws`、`门内` 与相关生成源；分别验证身份、地域和各境界的输出。

既有设计依据：[宗门细化工作流程.md](宗门细化工作流程.md)。该文档的分档表主要对应凡界；下文另外列出灵界实际使用的分档。

## 实际触发方式

门内视角补充宗门内部的生活与修炼信息，追加在该宗 `detail` 后面。它与人物文件的 `moderate / detail` 分档无关。

| 判定项 | 当前实现 |
| --- | --- |
| 世界与地域 | 对应总览必须处于 `in` 模式，即玩家身处该世界的本域／本大陆 |
| 宗门身份 | 将 `stat_data.身份` 数组拼成文本，检查是否包含本宗 `门内kws` 中任一词 |
| 境界 | 读取 `stat_data.修炼进度.境界`，选择该总览公共的四档之一 |
| 实际位置 | 不要求 `具体地点` 正好是宗门驻地；身处同域／同大陆且身份匹配即可 |
| 聊天关键词 | 不是门内归属条件；聊天提到宗门并不会自动成为该宗弟子 |
| 多重身份 | 总览逐宗检查；如果多个宗门的关键词都匹配，可以同时追加多个宗门的对应档 |
| 输出正文 | 仅追加选中的一档，不将四档一起输出；每档正文以 `[门内视角]` 开头 |

既有流程文档中的“最多一个宗门的一档”并非当前代码强制限制。关键词是子串匹配，未来修改简称时须核对是否误命中其他身份。

## 创作时待指导的事项

以下只记录现状和需要讨论的差异，不在本轮改写正文。

- 五毒教等凡界成品已经列出具体功法书、技艺书及部分机制效果，可作为细写程度的对照。
- 灵界不少宗门使用“传承方向＋概括性的技艺书说明”，具体可修内容与档位差异较少；“传承方向”与“技艺书”存在复述。
- 灵界多份四档正文反复出现相同的“取用”说明，部分日常段存在“日常: 日常：”等重复前缀，后续可按用户要求统一处理。
- 分档是否维持大陆公共规则、是否按小宗组织规模另作安排，待创作时决定；本轮不改触发逻辑。
- 未配置的 24 个条目仅登记为缺项，不预设必须全部新增；由用户选择创作范围。
- 既有流程将门内层定位为入门、日常、修炼与资源，宗门主线另行创作。功法、书目、资源和获得条件如何写，以后续指导与确认稿为准。
