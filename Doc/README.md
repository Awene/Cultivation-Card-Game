# 《本格数值化修仙》Doc 核心知识库与文档结构规范

本目录是项目的**核心知识库、数据底表（Source of Truth）、系统架构方案与历史专项重构交付证据**。

> [!IMPORTANT]
> **AI 与开发者维护准则**：
> 1. **严禁在 `Doc/` 根目录下随意平铺新增文件**。所有新文档、数据表或工具必须按以下五大分类放入对应子目录。
> 2. **数据底表保留相对路径**：`世界书设定相关/` 目录下的 CSV 文件（如 `角色蓝图.csv`、`秘境清单.csv` 等）是编译脚本与数据生成器的源数据，切勿随意移动或改名。
> 3. **根目录保留项**：`Doc/DOC.md` 供外部仓库与快速指引链接使用，保持根路径不动。

## AI 维护指引（供后续 AI 参考）

当后续 AI 在处理开发任务时，应遵循以下规则维护 `Doc/`：

1. **产出新文档时**：
   - 如果是制定新的编码、世界书格式规范或审核条件，放入 `01-规范与开发指南/`。
   - 如果是设计新的底层系统（如交易行、战斗引擎），放入 `02-系统架构与设计/`。
   - 如果是单次专项改动、分支整合、用户反馈汇总的验收总结，放入 `03-专项重构与验证/`。
   - 如果是单次辅助小脚本或样本，放入 `04-辅助工具与样例/`。
   - 如果是世界观背景、国家、人物总设定，放入 `世界书设定相关/`。
2. **严禁破坏设定数据**：
   - 严禁随意清空或更改 `世界书设定相关/` 内 CSV 文件的列结构与编码（UTF-8）。
3. **保持根目录整洁**：
   - 保持 `Doc/` 根目录只保留 `README.md`、`DOC.md` 及标准分类目录。
