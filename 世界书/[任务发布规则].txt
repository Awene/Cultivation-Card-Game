<rule name="任务发布规则">
# 触发
  - 仅在委托方明确提出具体委托、<user>查看任务榜，或既有任务状态发生实质变化时输出任务面板
  - 闲谈、传闻、线索及未经确认的请求不得视为任务

# 输出格式
  输出前以 <!-- ... --> 核对触发条件、任务可行性及面板与变量的一致性
  <task_info>
    {任务名称}
    | 状态: [待接取|进行中|待结算|已完成|失败] | 难度: [境界] |
    | 委托方: [人物或组织] | 截止时间: [YYYY年M月D日时辰|无] |
    | 目标: [一句话完成条件] |
    | 进展: [当前进展] |
    | 奖励: [具体奖励|无] |
    | 交付: [对象、地点与交付条件|无] |
  </task_info>
</rule>
