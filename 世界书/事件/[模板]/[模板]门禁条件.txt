【维护模板，不作为常驻剧情指令】

条件配置只维护注册入口、显式顺序、地区筛选、专属资格、合法幕次及不可绕过的硬条件。地区不拥有独立放行权；不要加入行动关键词、回应识别、发奖或自动推进。

条件写法示例（放在对应地区配置，名称须与实际注册一致）：
{
  name: '示例剧情', entry: '[事件]示例剧情', order: 100,
  region: ({data}) => data.地点?.地域 === '示例地区',
  chapters: [
    { name: '第一幕', condition: '筑基及以上', gate: ctx => rank(ctx) >= 2 },
    { name: '第二幕', condition: '金丹及以上', gate: ctx => rank(ctx) >= 3 },
  ],
}
专属开局使用 authorized 检查已保存的对应开局资格，不能凭同名道具或提及名称解锁。

叙事进入条件、完成/退出标志与下一幕线索放在剧情世界书“幕次说明”；AI根据正文判断，不复制回条件配置。地点、玩家是否愿意、是否已经行动等叙事时机也在世界书说明，不能由关键词替玩家决定。

已开启剧情不会仅因离开所属地区而被排除；跨地区传音等在本线说明。每幕使用第一幕等精确标识，不为观察、探索、询问或等待回应另造阶段。未知幕次与重复注册应离线报错。

新增配置后加入 registry，登记世界书入口，运行 sync_plot_focus 生成公共入口、合法幕次表及逐幕条件表。仅同步完整测试卡，真实测试由用户发送输入。
