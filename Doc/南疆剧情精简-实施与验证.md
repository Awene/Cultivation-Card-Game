## 已实现

- 常驻任务规则只保留委托；现行预设不再要求普通机缘、险境自动建卡。
- 四份南疆剧情移除固定选项、第五项追加及逐字段 Patch；保留故事、关键节点 task_info、奖励和精确阶段名称，以简短状态说明交给普通 MVU 更新。

- 删除剧情选项前缀识别、徽章、独立分组和专属样式。旧前缀作为普通文字显示并完整填入；普通编号、输入框追加与快捷回复保留。

## 验证结果

- 45 个离线 EJS 场景通过：开启、防重开、静默阶段、境界及在场门禁、收集、等待选择、各结局和六种日常的待回应衔接。它们验证模板输出与条件，不能证明模型一定遵守叙事或更新指令。
- 变量更新规则经 EJS 渲染后的 YAML 解析通过；前后端任务 Schema 对相同剧情输入得到相同结果，共享字段未被过滤。
- 正文脚本语法、委托/剧情解析、显式分类、旧前缀原样保留以及模式二/专属选项残留检查通过。
- 正文美化与修仙状态栏的生产构建通过；仅有既有的包体积提示。构建限定两个界面，跳过与本次无关的自动整卡打包和其他 Schema 重写。
- 浏览器加载真实构建产物进行样例界面验证：紫色剧情面板与委托面板正常；点击普通选项、带旧前缀选项和快捷回复都能向父输入框追加正确文字。截图为样例数据，非模型剧情实测。
- ESLint 未完全通过：TaskCardPlot.vue 中原有的直接修改 task prop 写法仍有 9 处报错，修改前同类报错有 10 处；本次删除祸福字段后少一处。未为此次精简重构整套编辑模式。
- 两个仓库 diff --check 通过。

## 复核入口

在前端源码目录执行：

```powershell
node scratchpad/test_nanjing_simplification.mjs
node scratchpad/build_nanjing.mjs
node scratchpad/make_nanjing_preview.mjs
```

第三条生成本地样例页面，需本地前端服务运行后打开 http://127.0.0.1:5500/scratchpad/nanjing-preview.html 。
