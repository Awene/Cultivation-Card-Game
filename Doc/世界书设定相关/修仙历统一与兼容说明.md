# 修仙历统一与兼容说明

## 正式设定

- 各界统一使用修仙历；地球复苏后，为更准确地推算灵气潮汐而转用此历。
- 地球复苏：7024年1月1日；北京入学开局：7026年1月1日。
- 环境系数节点仍为7026年、7030年、7050年，秘境开放日期只统一纪年，事件先后不变。
- 提示词、开局导出、正文时空栏、状态栏和变量直接使用修仙历。AI不承担历法换算。

## 代码兼容（不注入提示词）

- 明确标注公元、公历、AD或CE的旧输入：年份加5000。
- 地球中无前缀的1900—2999年按误填的现代旧年份纠正；其他世界的无前缀年份不自动平移。
- 支持年月日对象、数字字符串、带历法前缀的日期、中文数字和日期字符串。
- 正常修仙历日期跨界原样保留，重复解析不再次平移年份。
- 无效变量更新保留原值；无法读取地球日期时，以7026年1月1日为默认基准。缺失或无效月日用默认分量，不让无效日期落入最高灵气档。
- 同步处理出生年份、突破年份、世界推进起点、任务截止时间和资产收取日期；年龄、耗时及现实文件时间戳不换算。
- 年月日范围沿用原变量结构；本次不重设计月份长度、耗时或日期插值算法。

## 维护入口

- 日期兼容源：前端库 `util/cultivation-calendar.js`。
- 卡内变量结构与MVU核验内嵌完整函数；地球EJS内嵌日期函数；正文美化内嵌年份函数。副本以 `CULTIVATION_CALENDAR` 标记定位，保持与源文件一致。
- 世界书生成器读取同一日期兼容源，不再生成旧历显示或反向换算。
- 前端回归：`node scratchpad/test_calendar.mjs`；地球条目回归：角色卡库 `node scratchpad/test_earth.mjs`。
- 本卡剧情日期已统一；外部参考卡、开发记录的真实日期、第三方依赖和历史快照不属于游戏历法，不改写。
