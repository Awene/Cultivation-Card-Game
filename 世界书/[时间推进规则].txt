<rule name="时间推进规则">
触发机制: 仅当本轮玩家明确要求以[时间推进规则]进行世界演进时触发。修炼、突破、跨年本身不触发。
推演区间: 从变量「传闻.上次世界推进时间点」至本轮请求记录的「时间」；只补算这段已流逝的时间，不额外推进玩家时间。
时间校验: 当前时间必须晚于上次推进时间，哪怕只差一个时辰亦可；相等、倒退或日期无效时不执行、不更新推进时间点。
短期尺度: 不满一年时以日常活动、修炼积累、消息传播与既有事件进展为主；不得把一个时辰写成多年兴衰，不强行制造突破或灾难。
数据基准: 当前变量是现有事实，不得对已经结算过的年龄、修为、物品再次累计整段收益；仅补充尚未结算的变化。冥族沿用停龄规则。

# 第一阶段: 变迁参考表

  境界变化: 推演各角色的进阶/跨阶事件时,耗时区间参照 <realm_power_level/> 中的「境界耗时」表

  文明演进:
  | 时间跨度 | 典型表现 |
  | --- | --- |
  | 1~5年 | 王朝政令更迭、局部战乱、城镇人口流动 |
  | 5~30年 | 小国兴衰、新城建立或旧城荒废、民间信仰转变 |
  | 30~100年 | 王朝更替、民族迁徙、文化习俗演变 |
  | 100~500年 | 大国覆灭或崛起、语言分化、城市荒废或新建 |
  | 500~3000年 | 民族融合或消亡、文明断层、历史神话化 |
  | 3000年以上 | 语言面目全非、旧时代文明仅余遗迹与传说 |
  注: 修仙王朝（统治者为修士）发生的变化较小

  世界变迁:
  | 时间跨度 | 典型表现 |
  | --- | --- |
  | 1~5年 | 势力消长、人事更迭、局部战乱平息或爆发 |
  | 5~30年 | 宗门兴衰、灵脉枯竭或新生、秘境开闭 |
  | 30~100年 | 小宗门陨落、势力版图重划、部分地域面目全非 |
  | 100~500年 | 大宗门覆灭或崛起、山河改道、上古遗迹重现 |
  | 500~3000年 | 大陆格局重塑、种族兴衰、旧势力彻底湮没 |
  | 3000年以上 | 地形演变、海陆易位、旧时代彻底成为神话 |

# 第二阶段: 人物变化事件表
  每位人物在时间推进中可触发一次或多次事件（时间越长，事件链越长）
  事件链格式: [事件A] -> [事件B] -> ...

  | 事件类型 | 触发倾向 | 结算说明 |
  | --- | --- | --- |
  | 无变化 | 任意 | 修为略有精进但无实质突破，状态维持 |
  | 小境界突破 | 修为充足、无天谴 | 境界小进 |
  | 大境界突破 | 积累充足、有机缘 | 境界大进，实力质变 |
  | 取得机缘 | 任意 | 获得物品，需注明具体所得 |
  | 探秘受损 | 中低阶修士 | 秘境险境中受创，可能损失物品/境界倒退 |
  | 走火入魔 | 修炼激进/天谴高 | 境界倒退，可能获得永久减益状态 |
  | 被人追杀 | 有仇敌/持宝在身 | 损失物品/灵石，可能受伤/流亡/陨落 |
  | 势力变动 | 宗门动荡时期 | 身份/所属势力发生变化，如：叛出宗门、被驱逐、晋升长老 |
  | 仇怨结下 | 竞争/夺宝 | 新增敌对关系，后续事件链可能触发被追杀 |
  | 陨落 | 寿元耗尽/历劫失败/战败 | 从关系列表中移除，需注明陨落原因 |
  | 隐世闭关 | 高阶修士/受创后 | 从叙事视野中消失，下落不明，后续可能重出 |

  约束:
    - 事件链长度: 不满1年=0~1个实质事件，可描绘日常且无数值变化；1~30年=1事件；30~100年=2~4事件；100年以上=4~6事件
    - 连锁逻辑: 事件须符合因果，如[取得机缘]->[被人追杀夺宝]合理，[陨落]后不可再有事件
    - 寿元判定: 每次推进须对照寿命上限判断人物是否自然坐化（年龄≥寿命则必然陨落）
    - 知情边界: NPC镜头可以呈现其真实经历，但主角不会自动知道；面向主角传播的未证实消息用"据说""传闻"，不得把猜测直接结算为死亡或物品变动。

# 第三阶段: 逐人小面板与叙事
  人物清单: 以推演前关系列表中类型='人物'的全部条目为准，逐人展示，不遗漏不在场人物；傀儡、灵兽不单列为人物。此次陨落者也先完成展示，再按原规则移除。
  输出顺序: 每人一个完整<time_info>面板，紧接该人物经历的正文段落，然后再输出下一人的面板和正文。禁止把全员塞进一个大面板。
  时间面板: 正文开头的<tp>沿用原有要求。世界推进过程中的NPC镜头、世界变迁及其时间地点切换无需输出<tp>面板，推演区间由<time_info>标明；最终镜头转回<user>时再输出<tp>，使用本轮请求记录的玩家当前时间、当前地点及对应天气，不因NPC镜头改变玩家时间、地点。
  单人模板:
    <time_info>
      {人物推演}
      | [人物名] ([当前境界] / 年龄[X]/寿命[X]) |
      | 区间: [起点] 至 [终点] |
      | 事件链: [事件A] -> [事件B] / 日常无实质变化 |
      | 境界变化: [旧境界] -> [新境界 / 维持] |
      | 寿元变化: [年龄与寿命变化或维持] | 判定: [健在/自然坐化/陨落及原因] |
      | 物品变动: [获得/失去/无] |
    </time_info>
    随后镜头对准此人，以场景、行动、对话描绘区间内经历，而非复述面板清单。
  世界变化: 必要时另用小<time_info>面板，以{文明演进}或{世界变迁}记录一处势力/地域的变化，并接对应叙事；短期没有变化可省略。
  叙事指导: 允许镜头暂离<user>逐一跟随NPC；人物保持独立生活与动机。全员展示优先，正文目标2500-3500字（面板不计），人数过多时允许超出。最终镜头必须回到本轮请求记录的当前时间、当前地点的<user>，不替玩家行动、不把时间额外向后推进。

# 第四阶段: 变量与传闻结算
  - 正文明确公开消息的来源、发生地与线索，区分公开消息和NPC私密镜头，供变量更新AI提取；正文无需逐条叙述全部传闻类别。
  - 具体结算交由变量更新AI按[mvu_update][传闻更新规则]执行：固定10类各维护一条，优先沿用有效旧消息、合并同一事件、清理过期内容，并依据世界设定补齐缺失类别的背景传闻，不重复累计已结算的主角收益。
  - 完成后在同一JSONPatch最后写入 /传闻/上次世界推进时间点 = 本轮请求记录的当前时间；无新消息也更新，未完成或失败则不标记完成。正文叙述不能代替变量写入。
</rule>
