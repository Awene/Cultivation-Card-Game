<rule name="宗门建设规则">
# 适用条件
- <user>是资产的拥有者(宗主、店主、府主...)，且本轮实际实施该资产内设施的新建、改造、修复或拆除

# 参数声明:
  L=设施境界系数 Q=品质系数 k=生成系数，L/Q沿用核心系数表
  G(k)=floor(10^L×k×(1+Q))
  D=max(1,floor(L/2+2Q))                         # 命中/闪避固定加值
  Z(a)=L×(1+Q)×a%                              # 普通百分比，a按效果选取
  F=L×5%+Q×20%                                # 穿透/减免百分比
  R名=所属宗门名气
  N(k名)=max(1,floor((L+1)×(1+Q)×k名))          # 名气增量
  A商=round(10^L×k商×(1+Q),2)                  # 商业收益系数，保留两位小数

# 第一阶段: 建设方案与投入
  1. 确定操作：新建/升级(扩建、修复)/拆除
  2. 负责人：指定实际主持施工者，从其变量读取境界与相关技艺；负责人L≥目标设施L，包含小境界比较。
    | 施工内容 | 主判技艺 | 必要条件 |
    | --- | --- | --- |
    | 房舍、矿场、工坊与器具安装 | 炼器 | 施工器具、承重建材及对应设备 |
    | 灵田、灵泉与种植环境改造 | 培育 | 开垦器具、土壤与水源、对应种苗 |
    | 护山阵、聚灵阵与阵纹改造 | 阵法 | 刻刀、阵材、布阵场地 |
    - 每项工程取决定核心功能的一种技艺；复合工程按独立施工部分分别判定。丹房的建造用炼器，日后炼丹另用炼丹技艺。
  3. 目标：开工前明确用途、规模、目标境界、用料与工期；升级注明要提升的境界、品质或能力，目标境界不低于原设施；修复以恢复原状为目标。
    - 新建未指定境界时取核心主材境界；主材按核心建材中L最高、同L取Q最高者确定。主材L须≥目标L，场地与设备须能支持目标用途。
    - 核心建材按足够完成该工程的一套用量计算，重复堆料不增加判定次数或境界。凡俗建筑以主体木石为核心建材，目标L=0。
    - 升级与修复使用本次新增材料判定；原设施保留部分不作新增投入，新效果在完工后生效。
  4. 灵石门槛：每次新建、升级、修复均需支付建设费C=ceil(10^目标L×K)，单位为下品灵石；新建K=10，升级K=5，修复K=2。
    - 建设费包含人工与非核心施工耗材，核心材料另备；自建也需支付，已有材料不抵扣建设费。
    - 读取<user>当前灵石；灵石<C则本次建设直接失败，不扣灵石和材料。等于C可开工，后续收益不计入可用余额。
  5. 开工：通过灵石门槛后核对负责人境界、技艺、器具与材料；条件齐备时一次扣除C及本次实际使用的材料，再进行建造判定。施工失败不退已付建设费；同一工程续建不重复支付，失败重试重新支付。

# 第二阶段: 建造判定
  1. 基准：Vt=10^目标L，Vu=10^负责人L。建设每次判定一项工程，不使用批量乘数。
  2. 素材：参与核心功能的主材与辅材决定品质区间；Min_Q为最低品质，Max_Q为最高品质，非核心的普通砖木与燃料不参与定阶。
    - 主材能效=10^主材L×(1+主材Q)。
    - 辅材能效=10^辅材L×(1+辅材Q)×E；辅生主E=1.5，主生辅1.2，无生克1，相克0.5。
    - P_mat=主材能效+能效最高的前三种辅材之和；同种材料合并为一组，不按件数重复加值。
    - D_mat=Σ(0.5×10^素材L)，计入主材与每种实际投入的核心辅材，未进入前三的辅材也计入难度。
  3. 对抗：
    P_build=Vu+对应技艺值+工具加值+火焰加值+阵法加成+功法加成+P_mat
    D_build=2×Vt+D_mat+无图纸惩罚
    Δ=P_build−D_build
    - 同类加成取最高且须用于本次施工；火焰仅用于需要熔炼的炼器工程。新设施或本次升级尚未生效的能力不计入加成。
    - 无可用图纸或已掌握的营造方案时，惩罚=0.5×Vt，否则为0；既有设施的原样修复视为有方案。
  4. 结果：
    | 差值 | 建造结果 | 候选品质 |
    | --- | --- | --- |
    | Δ<0 | 失败 | 无 |
    | 0≤Δ<0.5×Vt | 成功 | Min_Q |
    | 0.5×Vt≤Δ<Vt | 优秀 | Min_Q提升1阶 |
    | Δ≥Vt | 极品 | Min_Q提升2阶 |
    - 品质按凡→黄→玄→地→天升阶，最终不超过Max_Q；升阶后再查Q系数。
    - 新建成功：设施境界=目标境界，品质=候选品质。升级成功还须达到声明目标，且品质不低于原设施；未达标按失败结算。
    - 修复成功：恢复原境界、品质与原有能力；要求候选品质≥原品质。添加能力或提升品阶按升级判定。
    - 失败：消耗本次已使用的施工材料，新建不生成可用设施，升级或修复保留原设施及受损状态；重试须重新投入。
    - 成功且工期完成后，用最终L/Q生成效果和每月产出；升级只改动本次涉及的能力，未改变的生产安排沿用原值。

# 第三阶段: 拆除与回收
  1. 拆除直接成功：可拆卸器具按实际损耗返还；已融入建筑的结构材料各回收floor(原留存数量×0.5)，境界、品质沿用原材料。
  2. 建设费、人工、燃料与已消耗物资不回收；缺少用料记录的旧设施，只回收剧情明确存在的残材，不按设施品质反推稀有材料。
  3. 拆除前结清已完成周期，待领灵石计入本次回收；已成熟且实际收取的物资另行结算。按物品规则记录回收物后移除设施，终止效果与产出，调整下游供给。

# &RULE_设施生成原则:
  1. 境界与品质：采用建设判定结果；改造只提升本次投入支持的能力，不随宗主境界变化。
  2. 效果数量：凡/黄=1条，玄/地=2条，天=3条；优先从所属设施的效果枚举中选取，体现专精。
  3. 效果写法：条件+适用对象+具体作用/数值；非数值能力注明境界、地域或品类范围，沿用物品词条风格。
  4. 能力限制：效果在设施正常运转且实际使用时生效；教学、生产与调查仍需相应传承、配方或消息来源。
  5. 数值分工：G用于固定能效，D仅用于命中/闪避，F用于穿透/减免；不增加气血/灵气上限，不把临时加值写入人物基础属性。

# &RULE_设施效果系数表:
  | 效果类型 | 计算方式 | 结算位置 |
  | --- | --- | --- |
  | 培育/勘察/调查等技艺辅助 | G(k=0.1~0.3) | 对应非战斗检定的技艺加值 |
  | 参悟辅助 | G(k=0.1~0.2) 或 Z(a=1~2) | 领悟能效P的W或Z，仅作用于本次检定 |
  | 炼丹/炼器等器具辅助 | G(k=0.5~1.5) | 生产制作的工具加值 |
  | 地火等火源辅助 | G(k=0.5~1.5) | 生产制作的火焰加值 |
  | 驻地攻击/防御辅助 | G(k=0.1~0.2) | 对应攻击力/防御力加值 |
  | 命中/闪避修正 | D | 对应d20检定 |
  | 穿透/减免修正 | F | 对应穿透%/减免% |
  | 聚灵修行辅助 | Z(a=0.5~1) | 修为获取的修行速度Z% |
  | 每月名气 | N(k名=1~2) | 正常运转每满一月，增加所属宗门名气 |
  | 活动名气 | N(k名=3~5) | 每完成一次词条指定活动，增加所属宗门名气 |
  | 商业营收 | A商×R名，k商=0.01~0.05 | 每月净收益，实收向下取整 |
  同类来源的叠加沿用对应规则；工具、火焰各取最高。检定辅助不同时计入技艺成长奖励。
  名气与营收均为可选效果，占用效果条数；k依据设施规模、传播范围或经营条件选定，建成后固定。

# &RULE_设施效果枚举:
  下列为候选词条，按品质选取，不默认全有；规模、覆盖区域与关键运转条件并入词条说明。

  灵田:
    - 灵植培育：在此培育${指定属性/种类}灵植时，培育技艺视为增加${G(0.1~0.3)}。
    - 定向供药：按既定配方培育${指定药材}，供${丹房名}使用；产量记入每月产出。
  矿场:
    - 矿脉勘察：在本采区探查矿脉走向时，神识技艺视为增加${G(0.1~0.3)}。
    - 矿料精炼：可分选、提纯${L对应境界}及以下的${指定矿材}，供${器坊名/阵法用途}使用。
  商铺/交易类设施:
    - 交易渠道：在${城镇/商路}收购、出售${L对应境界}及以下的${指定品类}，稀有货物需具体供货方。
    - 议价支持：借助本铺行情与人脉进行交易交涉时，所用幻术或神识技艺视为增加${G(0.1~0.3)}；仍按实际交涉结果成交。
    - 货物鉴别：在铺内借助对应鉴定器具检查${指定品类}时，相关生产技艺视为增加${G(0.1~0.3)}。
    - 商业营收：经营${主营品类}时，每月产出${预先算出的A商}×名气灵石（净收益，含日常进货与经营开销）；名气取宗门当前名气值。
  藏经阁:
    - 馆藏传承：收藏${属性/技艺方向}传承，可研读至${完整篇章对应境界}；特色传承${至多2部名称}。
    - 参悟辅助：在阁内研读${指定方向}传承时，领悟能效增加${G(0.1~0.2)}或${Z(1~2)}，二选一。
    - 授业条件：具备${传承与师长}时，可教授至${两者能力上限中较低者}；习得功法仍按领悟规则处理。
  丹房/器坊:
    - 配套器具：在此${炼丹/炼器/制符/制傀/制作阵物}时，工具加值为${G(0.5~1.5)}。
    - 配套火源：使用${已有火源}进行炼丹、炼器或制傀时，火焰加值为${G(0.5~1.5)}。
    - 专项量产：已有${配方、人员和原料渠道}时，持续生产${指定成品}；单次炼制按生产制作规则，常规供给记入每月产出。
  情报据点:
    - 地域耳目：搜集${已建立关系网的地域}的${秘境/商路/势力动向之一}线索，注明消息来源和待核实部分。
    - 调查支持：在该地域借助据点调查时，所用神识或幻术技艺视为增加${G(0.1~0.3)}。
    - 隐秘联络：通过${已有暗号/信物/隐蔽路线}联络时，规避${L对应境界}及以下的常规追查；主动侦破按非战斗判定处理。
  接引院/论道场:
    - 定向招募：面向${地域}招收${灵根/技艺条件}的弟子，说明测试、接待及供养能力；实际录取后更新人员规模。
    - 论道辅助：有相应参与者交流${指定方向}传承时，领悟能效增加${G(0.1~0.2)}或${Z(1~2)}，二选一。
    - 宗门交流：可承办${层次与规模}的论道、比武或来访接待，名气与关系随实际活动改变。
    - 活动扬名：每完成一次${比武/招生/宴会/论道中指定的活动}，宗门名气增加${N(3~5)}；活动开始或筹备不结算。
  护山大阵:
    - 守山屏障：运转时，${覆盖区域}内受保护目标防御力增加${G(0.1~0.2)}，或减免增加${F}，二选一。
    - 迷阵阻敌：阵内${L对应境界}及以下敌人的命中减少${D}。
    - 隐匿山门：对${L对应境界}及以下的常规探查隐藏${指定区域}；主动勘破按非战斗判定处理。
    - 聚灵修行：在${指定区域}内打坐时，修行速度增加${Z(0.5~1)}；同一聚灵来源已计入E_local时不再重复加成。
  通用名气效果:
    - 声名远播：${展示、接待或传播渠道}正常运转时，每满一月宗门名气增加${N(1~2)}；结算至${投产时间}。
    - 月度与活动增量均预先算成整数；同一活动每个符合条件的设施效果结算一次，不按参与人数重复增加。

# &RULE_设施每月产出:
  1. 物资产出：
    月产值基准 V=G(k产)；单件价格P按当前世界经济系统，以实际产品境界、品质和计量单位确定。
    | 设施 | k产区间 | 产出范围 |
    | --- | --- | --- |
    | 灵田 | 1~5 | 已有种苗与种植法支持的灵药 |
    | 矿场 | 3~10 | 矿脉实际蕴含的可用矿材 |
    | 丹房/器坊 | 5~15 | 已有配方与人员可稳定制作的成品 |
    - 产品境界、品质由实际种苗、矿脉、配方和生产能力确定，不直接等同设施的L/Q。
    - 依据有效规模与供应条件在区间内选k产；常规满月产量N=floor(V/P)，单位与P一致。V是换算基准，不再另发同额灵石。
    - 多种产品按用途分配V，各产品分配额之和≤V；每种产品用分得的V计算，分配为0的产品不记产出；同批原料转入下游后，不再计为可领取或可出售的上游产物。
    - 若V<P，记录“每ceil(P/V)个月产1件”；实际成熟期或制作周期更长时取较长者。长周期产物在到期时领取，不逐月生成小数物品。
    - 建设时将数量、周期与必要条件固化为文字；价格波动不重算物理产量，改建或供应改变时再调整。单次亲手炼制占用同一原料与工期，不重复计入常规供给。
  2. 灵石收入：
    交易类设施采用商业营收效果：月净收益=floor(A商×R名)。
    - 根据经营规模与供货条件选k商，先用设施L/Q算出A商；效果与每月产出均保留“数值×名气”的公式，不把名气代入后固化为收入。
    - 示例：L=2、Q=0、k商=0.04，A商=4，写“每月产出4×名气灵石（净收益）”；名气为20时该月收益80灵石。
    - 营收效果与每月产出是同一份收益；日常进货和经营开销已计入系数，不再另扣。尚未具备供货与经营条件或停业期间不产生收益。
    - 宗门自产货物用于该商业营收时，从可领取产物中划出；同批货物不再另发销售收入。
  3. 信息与非生产设施：
    - 情报据点：每月可核查max(1,floor(1+Q))条指定地域、类别的新线索；记录为能力上限，实际结果可为0，重大秘境与内部机密需具体来源。
    - 非生产设施无物资、灵石或月度名气效果时，每月产出为“无”；有月度名气效果则写明对应增量。活动名气仅写效果，活动完成时结算。
  4. 字段写法：
    - 物资：“${物品名}×${数量}${单位}/月；${境界、品质}；需${关键条件}；${内供/留存分配}”。
    - 长周期：“每${周期}个月产${物品名}×${数量}${单位}；首次成熟/完成于${时间}”。
    - 收入：“${已算出的A商}×名气灵石/月（净收益）；主营${品类}；本期计价名气${数值}；待领${金额}灵石；结算至${时间}”。
    - 月度名气：“宗门名气+${已算出的N}/月（对应${效果名}）”；与效果为同一笔增量。
    - 情报：“每月至多核查${数量}条${地域·类别}新线索；需${关系网}”。
    - 无产出：“无”；临时停产保留原公式与结算记录，在概况注明停产原因及时间。

# &RULE_设施周期结算:
  1. 仅结算投产后正常运转的完整月份；初建时，月度名气效果与商业每月产出中的“结算至”均填投产时间，商业待领为0，本期计价名气填当时宗门名气。
  2. 按时间先后结算。同一时点先将全部到期商业收益加入各设施待领金额，再增加到期月度名气与同刻已完成活动的名气，最后用新名气记录这些商业设施下一期的计价名气。期中活动增加的名气从下一周期计价。
  3. 每次结算更新对应文字中的“结算至”；未满月与停产时段不计。名气变化不重算已完成周期，待领金额不按新名气重新估值。
  4. 领取商业收益时，从待领金额扣除实领部分并增加<user>灵石，更新上次收取日期；保留周期起点与计价名气，不再次增加名气。
  5. 停产、复产或改造时先结清已完成周期；剩余待领金额保留，新的周期以复产时间与当时名气为起点。旧设施缺少结算依据时，从本轮时间建立起点。

# 建设变更与变量记录
  1. 在建：宗门现状简记负责人、目标、已付建设费、已投入材料、判定结果与剩余工期；续建沿用该结果，完工后清除施工说明并写入设施。
  2. 升级/修复：保留其他有效词条及上次收取日期。物资产出改变前，未领取产物按旧产量算至生效时间，暂记于每月产出说明；新产量从该时起算，领取后清除旧段。商业沿用待领金额与周期结算记录。仅计算实际生产时段，施工停产期间不计产出。扩展传承、引入地火、取得阵图等须有实际来源。
  3. 沿用路径：固定资产.${宗门名}.设施.${设施名}，填写境界、品质、效果、每月产出、上次收取日期。
  4. 效果为“词条名: 描述”的字符串字典；“概况”简记规模及投产/首次成熟时间，“用料”简记仍留存建材的名称、境界、品质、数量，供改建与拆除结算；两项均不占效果条数。改建后更新留存用料，不积累施工流水。
  5. 上次收取日期：新设施为null，实际收取后才更新；首次领取从真实投产或成熟时间起算。建设、支付、回收、领取只记录实际发生的变化，不重复扣除。
  6. 宗门名气按设施月度效果、已完成活动及实际传播事件更新；建成时只登记效果，尚未满足周期或活动条件不发放。普通同类设施合并，藏书和成员只作必要概括。

# 设施生成格式
  按已执行阶段输出以下action_info面板，算式填写实际代入值与结果；加值注明来源，无加值填0。
  资金不足止于建设检查；其他前提未满足时不扣费、不进入数值对抗。续建只引用已保存结果及本轮进度。完工面板只列本次生成或改变的效果，不输出未采用的公式行。

  ## 建设检查与素材分析
  <action_info>
    {建设检查}
    | 宗门: [名称] | 操作: [新建/升级/修复] | 设施: [名称] |
    | 建造负责人: [人名、境界] | 目标境界: [境界] | 境界门槛: 负责人L[数值]≥目标L[数值] -> [通过/未通过] |
    | 目标基准Vt: 10^[目标L]=[数值] | 负责人基准Vu: 10^[负责人L]=[数值] |
    | 建设费C: ceil(10^[目标L]×K[10/5/2中实际值])=[数值]灵石 |
    | 资金门槛: 当前灵石[数值]≥C[数值] -> [通过/灵石不足，建设失败] |
    | 施工条件: 技艺[名称与数值]；器具[名称]；主材L[数值]≥目标L[数值]；材料数量[足够/缺少什么] |
    | 本轮支付: [未开工为0；开工为C]灵石 | 支付后余额: [原余额]−[实付]=[剩余]灵石 |
    | 本轮用料: [实际扣除的材料名称、数量] | 工期: [本轮经过时间/剩余时间] |
    {素材分析}
    | 主材: [名称、用量、L、品质与Q、五行] | 主材能效: 10^[L]×(1+[Q])=[P_main] |
    | 辅材: [名称、用量、L、品质与Q、五行] | 生克E: [关系、系数] | 能效: 10^[L]×(1+[Q])×[E]=[数值] |
    （每种核心辅材一行）
    | 有效辅材: [能效最高的前三种及数值，不足三种按实际] |
    | 素材能效P_mat: 主材[P_main]+[选中辅材逐项数值相加]=[总值] |
    | 杂质难度D_mat: 0.5×(10^[主材L]+[全部核心辅材逐项10^L相加])=[总值] |
    | 品质区间: Min_Q=[最低品阶] | Max_Q=[最高品阶] |
  </action_info>

  ## 数值对抗与品质结算
  <action_info>
    {建造判定}
    | 能力P_build: Vu[值]+技艺[值]+工具[来源/值]+火焰[来源/值]+阵法[来源/值]+功法[来源/值]+P_mat[值]=[总值] |
    | 方案检查: [已有图纸/已掌握方案/无方案] | 惩罚: [有方案填0；无方案填0.5×Vt及结果] |
    | 难度D_build: 2×Vt[值]+D_mat[值]+惩罚[值]=[总值] |
    | 差值Δ: P_build[值]−D_build[值]=[结果] |
    | 阈值: 0；0.5×Vt[值]=[优秀门槛]；Vt=[极品门槛] | 判定: [Δ所在区间] -> [失败/成功/优秀/极品] |
    （Δ≥0时）
    | 品质推导: Min_Q[品阶]提升[0/1/2]阶 -> [品阶]；封顶Max_Q[品阶] -> 候选[品阶] |
    | 目标核对: [新建采用目标境界与候选品质；升级核对目标及候选品质≥原品质；修复核对候选品质≥原品质并恢复原状] |
    | 最终结果: [失败/在建/完工] | 设施境界: [新建失败无设施；其他填本轮实际保留或生效的境界] | 品质: [实际品阶与Q] |
    （失败或尚未完工时）
    | 当前状态: [旧设施保留/新建未成/剩余工期] | 已付费用与已用材料: [本轮消耗，不退还] |
  </action_info>

  ## 完工效果与产出
  <action_info>
    {设施完工}
    | 设施: [名称] | 境界系数L: [值] | 品质: [品阶] | 品质系数Q: [值] | 效果条数: [凡/黄1，玄/地2，天3中实际值] |
    | 词条定标: [效果名] | 选用系数: [k或a的值、对应规模/条件] |
    | 固定加值G: floor(10^[L]×[k]×(1+[Q]))=[结果] |
    | 命中/闪避D: max(1,floor([L]/2+2×[Q]))=[结果] |
    | 普通百分比Z: [L]×(1+[Q])×[a]%=[结果]% |
    | 穿透/减免F: [L]×5%+[Q]×20%=[结果]% |
    | 名气增量N: max(1,floor(([L]+1)×(1+[Q])×k名[值]))=[结果] | 触发: [每满一月/指定活动完成] |
    | 商业系数A商: round(10^[L]×k商[值]×(1+[Q]),2)=[结果] | 营收效果: 每月产出[算出的A商]×名气灵石（净收益，实收向下取整） |
    | 非数值效果: [适用条件、范围与能力来源] |
    | 效果落地: [效果名: 最终描述；有多个效果时逐条列出对应计算与描述] |
    （有物资产出时）
    | 月产值V: floor(10^[L]×k产[值]×(1+[Q]))=[结果] |
    | 产品定价P: [物品名、境界、品质、计量单位及经济系统定价算式]=[单价]灵石 |
    | 产值分配: [各产品分得的V，总和≤V] | 月产量: floor([该产品分得V]/[单价P])=[数量] |
    | 长周期: ceil([P]/[分得V])=[月数]；实际成熟/制作需[月数] -> 取较长者[最终周期] |
    （仅该产品分得V<P时输出长周期行，分配额为0的产品省略）
    | 每月产出: [保存固定数量或数值×名气公式；有商业收入则同时填写本期计价名气、待领金额与结算时间] |
    | 投产时间: [时间] | 名气结算记录: [有月度效果时，填写结算至时间] | 用料记录: [仍留存的建材] |
  </action_info>
