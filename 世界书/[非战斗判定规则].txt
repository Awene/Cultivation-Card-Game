<rule name="非战斗判定规则">
# 参数声明：
  角色L = 角色当前境界系数
  挑战L = 判定对象/环境对应的推定境界系数
  Vg = 有效成长基准值 = 10^min(角色L, 挑战L)
  [Z%] = 相关增减益%
  [W] = 相关增减值

# 核心触发条件:
  激活：当<user>在非战斗状态下，试图克服具有不确定性或风险的客观阻碍时（如：破解机关、忍受极寒、勘破幻象、威压交涉等）。
  略过：当 角色L ≥ 挑战L + 2 时自动成功，不输出计算面板。

# 第一阶段：确定判据
  依当前情景，判断的唯一的关联三维与唯一的关联技艺，作为判据：
  | 示例场景 | 关联三维 | 关联技艺(选择其一) |
  | --- | --- | --- |
  | 感知异常、精神震慑 | 气感 | 神识 |
  | 抵抗极端环境 | 根骨 | 炼体 |
  | 破解非战斗阵法、机关解谜 | 悟性 | 阵法 |
  | 鉴别物品、学识比拼 | 悟性 | 相关生产技艺 |
  | 讲价博弈、拷问情报、蛊惑心智 | 气感 | 幻术 / 神识 |
  | 驯服妖兽 | 气感 | 驯兽 |
  | 医疗、手术、下毒 | 气感 | 医术 |
  ....

# 第二阶段：难度推定与公式化
  1. 难度系数 (C_diff) 设定：
     简单=0.5 | 寻常=1.0 | 困难=1.5 | 极难=2.0
  2. 角色能效公式 (A):
     A = floor( (10^角色L + 关联三维×5 + 关联技艺) × (1+[Z%]) ) + [W]
  3. 目标难度公式 (D):
     - 静态判定 (机关/陷阱/环境/无意识阻碍 — 不具备三维的客观对象):
       D_static = floor(10^挑战L × C_diff) + 10(固定)
     - 动态对抗 (具备三维的有意识对手 — 修士/妖兽/灵识):
       D_dynamic = floor( (10^挑战L + 敌关联三维×5 + 敌关联技艺) × (1+[Z%]) ) + [W]
  4. 差值阈值 (Δ) 与 结果阶层:
     Δ = A - D
     - Δ ≥ 10^挑战L × 0.5 : 【大成功】
     - 0 ≤ Δ < 10^挑战L × 0.5 : 【成功】
     - -(10^挑战L × 0.5) < Δ < 0 : 【失败】
     - Δ ≤ -(10^挑战L × 0.5) : 【大失败】

# 第三阶段：技艺实践增长
  1. 触发条件: 本次采用了一项具体关联技艺时
  2. 结果系数: 大成功=0.2 | 成功=0.1 | 失败=0.05 | 大失败=0
  3. 实践增长: Max(0, floor([Vg] x [结果系数]) × (1+[Z%]) + [W])
