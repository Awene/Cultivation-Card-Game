# 统一剧情调度：按幕维护（2026-10-31）

本次仅接入梦茧、五毒圣女、万毒祖窟；五毒教日常仅跟随无剧情模式门禁。其他地区保持原行为。

## 分工

前端 `src/修仙状态栏/plotScheduling/core.ts` 负责注册校验、硬条件筛选与当前幕的阅读范围；`regions/nanjiang.ts` 保存注册信息、排序及修为／身份／资格门槛；`registry.ts` 汇总注册。没有行动关键词、回应识别或脚本结算。

各世界书顶部的“幕次说明”维护叙事进入条件、完成或退出标志、下一幕线索；下方按本幕提供剧情内容。幕间未达到硬门槛时只有摘要，达到门槛不等于已开场。AI 根据正文与玩家真实行动选择是否演出，当前正在进行的幕优先，每轮最多开启一幕。

公共条目 `[公共]统一剧情调度` 由 getwi 按需执行。每次调用读取一份状态快照，不修改变量；返回 title（仅当前正在进行的幕）、candidates 与 diagnostics。候选包含 phase、active、eligible、condition、order。多处调用各读一次，不声称全轮只执行一次。

## 新增剧情

1. 在地区配置新增 PlotDefinition，填写 name、entry、order、region、可选 authorized、chapters。每幕只配置 name、硬条件摘要 condition 与 gate。不要添加 matches、response、细碎阶段或奖励结算。
2. 世界书按大型事件模板维护 `幕次说明` 与每幕正文，条件细节在本线维护，不将剧情正文加入公共入口。
3. 将世界书入口加入完整卡导出配置；运行 `node scratchpad/sync_plot_focus.mjs`。生成器校验入口与幕次，生成公共运行条目、变量脚本合法幕次表和审阅条件表。
4. 实际开启写阶段、幕次和本幕进行中=true；结束本幕只写 false、进展及下一幕线索；只有整线真实结束才归档并移除历练。
5. 自由模式实际开幕后显示聚焦，结束后回自由；手动选择不代替开启；无剧情模式只能由玩家解除。

## 验证入口

当前采用 `scratchpad/test_plot_chapters.mjs`（按幕读取、EJS、变量结构及聚焦）与 `scratchpad/test_opening_plot.mjs`（真实开局初始化）。旧 test_plot_modes、test_unified_plot、test_nanjing_simplification 保留为旧状态机历史用例，不再作为当前验收入口，其旧通过数不计入本次结果。

离线校验不能证明 AI 已在真实对话中正确判断完成标志、发放奖励或不重复弹卡。新开局测试由助手建议输入、用户发送并反馈，不自动调用模型。
