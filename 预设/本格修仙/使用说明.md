# 本格修仙预设 · Prime 架构

架构源于命定·黄昏 Prime-1.11，已对照 Prime-1.18 与通用版 v1.0.0 更新噪声和部分提示词写法，保留本卡的规则、变量和正文格式。入口仍为 `index.yaml`；可导入文件为 `本格修仙-test.json`。

## 日常设置

直接使用酒馆预设条目开关，没有悬浮球或额外设置界面。

| 设置 | 操作 |
| --- | --- |
| 语言与字数 | 修改最上方 `⚙️语言字数设置` 中三项值；普通回合和世界推进分别设置 |
| 头部输入噪声 | `⚙️ 头部输入噪声（Prime方式）` 默认关闭；开启后在首条有效系统消息注入噪声，默认每次生成变化 |
| 模型 | 四个 `🔌 …头部` 中只开一个；默认 Gemini |
| 思维链与尾部 | 中文、英文两条思维链均保持开启；Claude 自动使用英文，其他模型使用中文；四个尾部仍按模型头部选择，正文按语言设置 |
| 变量 | `🧭变量主API(二选一)` 与 `🧭变量额外API(二选一)` 只开一个；默认额外 API，开局/状态栏原有切换仍有效 |
| 玩家代写 | `⚙️ 允许抢话` 与 `⚙️ 禁止抢话` 二选一；默认禁止新增玩家自主言行 |
| 基调 | 三个 `🎭` 条目选一个；默认舒展叙事 |
| 进阶基调 | `🎭 进阶基调·轻松` 可叠加在基础基调上，默认关闭；内容沿用旧本格轻松基调，以 `<advance_tone>` 包裹 |
| 大纲展开 | 按需开启，按玩家大纲展开；不改变世界推进按钮的专用模式 |
| 难度 | 真实、简单、平然选一个；默认真实 |
| NSFW 路由关闭 | 显示已开启的防发情、SFW描写条目；两者默认开启 |
| NSFW 路由打开 | 显示已开启的男性向/女性向、词汇；默认男性向和词汇开启，女性向关闭 |
| NSFW 单项开关 | 直接开关相应条目；男性向与女性向建议只开一个，不再选择提示词来源 |
| 摘要与选项 | `📋 回复摘要`、`🎯 行动选项` 独立开关；默认都开 |
| 防截断噪声 | `防截断噪声（预设被路由或截断使用）` 位于最终输出格式之后，默认关闭；需要时手动开启 |

`📚` 结构条目（包括 `📚 正文结束`）、深度二/九百及后台脚本保持开启。模型头部名称是模板档位，不会替你切换 API 模型或供应商。

NSFW 条件读取路由插件写入的 `路由隐藏规则`：包含 `[mvu_plot][NSFW]基础指导` 表示关闭，否则表示打开。未路由、路由失败或列表异常时，沿用插件的“不隐藏规则”行为，不将其当作明确关闭。`🔧 NSFW可选` 条目只设置纯文本变量，不直接输出。词汇填入男女向模式尾部，SFW描写填入防发情模式尾部，均位于同一个 `<NSFW_content>` 内；对应模式关闭时可选内容也不输出。变量在每次请求开始清空，由模式条目的 EJS 延迟读取，不嵌套执行 EJS。

条目排版：顺序步骤用 `1.`，并列要求用 `-`，独立小节用 `##`，嵌套配置按两空格缩进；保留 XML 标签与 EJS 语法的结构。

## 依赖与首次切换

- 使用酒馆 1.16、酒馆助手和本卡原有的提示词模板/EJS扩展。
- 导入时允许该预设自带正则，酒馆原生负责绑定，无需 SPreset。
- 从旧预设切换后刷新一次酒馆，清理旧 SPreset/kemini 已注册的监听；不要同时启用旧预设脚本。
- 预设附带消息分区、头部噪声两个本地后台脚本，不添加界面、不远程加载预设助手。
- 本版使用普通正文输出，未接入参考预设的工具调用、输入转移或场外讨论助手。Gemini、Claude、Glm、DeepSeek 均保留用户消息结尾。
- 原生推理参数仍由酒馆与通道决定；提示词中的简短公开检查表不是 API 原生推理强度设置。

## 输出与总结

输出顺序保持为：

```text
<thinking>简短检查表</thinking>
<now_plot>
  <gametxt><tp>时间地点天气</tp>正文与规则面板</gametxt>
  <summary>摘要（启用时）</summary>
  <options>四个编号选项（启用时）</options>
</now_plot>
<UpdateVariable>变量更新（仅主API模式）</UpdateVariable>
```

实际标签为 `now_plot`，含下划线。原有正文美化、MVU与总结继续识别这些标签。保留最近历史正文，深度6及以上有摘要的助手楼层以摘要发送，无摘要时保留正文；不删除历史玩家输入。

世界推进由路由的 `[时间推进规则]` 自动选择五步群像检查：区间与人物、推进规则、状态与传闻、群像编排、输出核验。只补叙上次推进至当前时间，不额外推进玩家时间。额外 API 模式仅读取状态并融入叙事，变量更新仍交外部模型。

## 本地预览与打包

在角色卡仓库根目录运行：

```powershell
node 预设/本格修仙/模拟预设效果.mjs
node 预设/本格修仙/模拟预设效果.mjs --nsfw off
node 预设/本格修仙/模拟预设效果.mjs --profile claude --advance --mode main
node tavern_sync.mjs bundle 本格修仙预设
node tavern_sync.mjs push 本格修仙预设 -f
```

预览使用占位世界书与历史，仅验证宏、模板和消息分区；不能代替实际酒馆请求测试。`push` 目标仍是 `本格修仙preset-test`，不会更新 `发布文件` 中的历史版本。

## 宏兼容性

兼容酒馆旧宏引擎：`setvar` 的值不嵌套 `{{user}}`、注释或其他宏；玩家占位使用旧式 `<user>`，注释放在赋值之外。变量中不保存待执行的 EJS。

本地预览加载本机酒馆的变量宏定义，按旧引擎的处理顺序运行本预设使用的宏子集，再调用真实 EJS 引擎。`scratchpad/test_preset_macro_order.mjs` 可复现并检查玩家控制标签截断、注释泄漏和空推进字段问题。

## 两种噪声

- **头部输入噪声**：参考 Prime 1.18 的宏展开、分段噪声、固定/每次随机方式，由本地脚本独立实现。使用本格专用宏 `{{bengexiuxian_prompt_noise}}`，兼容普通宏引擎；不依赖命定助手。开启条目后，噪声在模型头部之前发送。
- **正文末尾噪声**：保留 `Doc/noise_L04000_fixed.txt` 的完整内容与 `{{random::…}}` 包装。原文件没有随机选项分隔符，因此每次发送同一整段。位置是“最终输出格式 → 可选噪声 → 正文结束 → 模型尾部”，整个预设只有一组正文开始/结束标记。

两者默认关闭，可分别开关。头部选项对应新版 Prime 的输入噪声，末尾选项保留此前指定的固定文件，并非新版 Prime 的原生位置。

在酒馆助手的预设脚本 `【本格修仙】头部噪声` 数据中修改：

| 设置 | 值 |
| --- | --- |
| 模式 | `random` 每次生成变化；`fixed` 固定内容 |
| 段数 | 10–48，默认 10 |
| 固定种子 | `fixed` 模式下相同值对应相同内容；换一个值即可换一份 |

同一请求内重复计算提示词使用同一份噪声；`random` 在下一次生成时换新内容。本地预览使用固定种子，便于比较。

这些功能改变发送文本，不会删除供应商缓存或决定实际调用的模型；随机头部也可能减少可复用的前缀缓存。更新后刷新酒馆，使本地脚本和宏重新加载。

## 提示词预览的空行清理

消息分区在预览阶段可能早于 EJS 执行。脚本在最终设置事件中也会识别已经分区的本预设消息，再清理 EJS 空分支留下的连续空行；保留历史消息、代码块和非文本附件。实验性宏引擎可保持关闭。更新预设脚本后刷新酒馆，使已运行脚本重新加载。

回归入口：`node scratchpad/test_preset_preview_whitespace.mjs`，覆盖预览先于 EJS、扩展较晚加载和当前生成结果样例。
