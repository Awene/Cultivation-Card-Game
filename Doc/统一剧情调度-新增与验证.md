# 统一剧情调度：新增与验证

当前仅注册梦茧、五毒圣女、万毒祖窟三条长线和五毒教日常集合。其他地区原条目尚未迁移，不受本次统一仲裁保证。

## 维护分工

前端工程 `src/修仙状态栏/plotScheduling/core.ts` 只负责通用仲裁；`regions/<地区>/<剧情>.ts` 保存独立条件；`registry.ts` 是注册表。地区没有独立选择权。`plotFocus.ts` 仅提供返回剧情名称的源码接口。

运行入口为世界书 `[公共]统一剧情调度`。条目关闭自动激活，由 EJS `getwi` 按需读取。每次调用读取一份 stat_data 与最新玩家输入快照，所有候选使用同一快照，不缓存跨轮结果、不修改变量。四份世界书与记录模型可能各自调用入口，并不声称整个生成过程只执行一次。

公共入口统一返回 JSON 对象：title、phase、kind（opening/advance/respond/none）、opening、advance、respond、diagnostics。世界书只消费这些决定；日常读取 title，空值时才评估本集合。不要传递全局函数或依赖条目加载顺序。

## 新增长线

1. 按独立条件文件编写下列接口，加入 registry.ts；名称、阶段字符串必须与世界书及历练一致。
2. 在角色卡导出配置中注册对应世界书入口与源码文件。生成器根据真实导出配置检查入口与文件，并双向核对配置阶段和世界书阶段，不接受空入口、重名、重复入口或漏阶段。
3. 世界书使用大型事件骨架，保留本线剧情、停笔点、状态说明；条件不再复制回世界书。
4. 在前端工程运行 `node scratchpad/sync_plot_focus.mjs`。生成器沿注册表自动收集模块依赖，隔离模块作用域，生成唯一公共条目、记录模型状态衔接与变量脚本合法阶段表。新增条件无需修改调度核心或打包模块列表。
5. 新增离线开启/回应/推进/分支/完成场景，通过后同步测试卡；真实测试由用户发送。

条件配置示例（仅说明接口，不注册到角色卡）：

```ts
import type { PlotDefinition } from '../../types';
export const example: PlotDefinition = {
  name: '示例剧情', entry: '[事件]示例剧情', order: 100,
  region: ({data}) => data.地点?.地域 === '示例地区',
  opening: ({data}) => data.身份?.includes('示例身份'),
  openingScene: ({data}) => data.地点?.具体地点 === '示例山门',
  authorized: () => true,
  matches: action => action.includes('示例信物') && !action.includes('暂不理会'),
  mentions: action => action.includes('示例信物'),
  response: action => /回应|回答|接过/.test(action),
  stages: {
    '初识': {
      advance: ({data}) => data.地点?.具体地点 === '示例洞府',
      respond: ({data}) => data.地点?.具体地点 === '示例山门',
    },
    '结局待确认': { advance: () => true },
  },
};
```

region 仅筛未开启剧情，已开启和手动聚焦线不会仅因身在异地被丢弃；后续节点自身的地点、世界或人物要求写在 advance/respond。专属出身限制放在 authorized，开场及后续都校验，不能以同名物品冒用开局。

matches 是明确正向行动，mentions 用于识别提及但明确离开的情况；response 只用于镜头仲裁，不代表玩家同意。它们都不能结算选择、奖励或完成。advance 是本阶段后续节点的资格，respond 是上一轮真实交互的现场条件；无需专门承接回应的状态节点可以不填 respond。

## 仲裁规则

- 无剧情模式返回 none；保留所有剧情状态。
- 手动模式优先指定剧情，明确离开该线不算接续。指定线暂无候选时只允许其他第一幕，不自动接续其他已开长线，不改玩家聚焦。
- 自由模式先取明确行动候选，再承接当前标题对应的眼前回应，再让位待回应日常，最后选择场景符合的新开场。旧标题本身不会推动已有剧情。
- 同级按 order 升序、名称确定性排序，不按注册先后，也不使用“最后一次关键词出现”决定剧情。
- 每次只返回一个节点。respond 与 advance 互斥，回应轮不能连演下一幕。实际阶段转换仍由世界书和普通 MVU 根据正文与玩家真实选择记录。
- 未知阶段、无效入口、重复配置、条件异常阻止相关候选并记录诊断；离线生成时直接报错。未注册线不猜测条件，不自动建卡。
