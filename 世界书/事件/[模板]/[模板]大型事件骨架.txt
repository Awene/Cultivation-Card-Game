【维护模板，不作为常驻剧情指令】

每幕是一段完整事件。各线保留自己的进度，脚本只做硬条件与记录检查；AI依据本轮行动和真实正文判断叙事时机与退出事实。

世界书读取结构：

  "第二幕": { "进入": "金丹后实际回到约定地点，愿意继续此事", "退出": "按本幕真实分支完成本次事件", "下一幕": "全线结束后归档" }
};
const 调度 = JSON.parse(await getwi('[公共]统一剧情调度'));
const 本线 = 调度.candidates.find(c => c.title === 本事件);

开幕记录阶段/幕次及本幕进行中=true；本幕退出记false、保留本幕进展与实际分支、更新下一幕线索、解除聚焦回自由。同轮不收束后直接开下一幕，未达到退出事实不反复重播开场。
全线真实结局或明确中断才归档并移除同名历练；奖励仅在实际获得时发放一次。无剧情模式只能由玩家解除。祖窟首幕继续由专属开局确认页初始化，不要求首轮正文重复插卡。
